# Contributing

Reproductions, independent counterexamples, mathematical corrections, citations,
and proposed provider-adapter test designs are welcome.

1. Open an issue identifying the manuscript section, figure, equation, or reference test.
2. Distinguish proved properties, modeled assumptions, and empirical observations.
3. Include a minimal reproducer and the expected versus observed behavior.
4. Submit changes through a pull request. Do not rewrite the archived PDF.
5. Keep external credentials, host paths, and any private incident data out of the repository.

Model tests and repository security checks must pass before merging. A green
workflow verifies the publication surface and finite models, not production safety.
