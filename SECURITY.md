# Security policy

NIGHTCRAWLER is a research publication with finite, synthetic reference models.
This repository does **not** run an agent control plane, expose an API, issue
credentials, or validate production providers.

For research corrections, provenance disputes, model counterexamples, or
reproducibility issues, open a GitHub issue with a minimal, sanitized reproducer.
Do not publish access tokens, account identifiers, private customer records,
secrets, or third-party confidential information in issues or pull requests.

For a sensitive security finding about repository code, use GitHub's private
vulnerability reporting if enabled. Otherwise contact the repository owner
without disclosing the sensitive material in a public issue.

The research PDF is SHA-256 pinned to the publication draft. CI has read-only
repository permissions and never publishes releases or modifies the deposit.
